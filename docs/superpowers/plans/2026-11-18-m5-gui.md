# M5 — Interface gráfica (Tauri 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Janela Tauri 2 que lista os discos ao vivo e executa fake-check, saúde, velocidade, formatação e histórico/laudo, delegando toda operação privilegiada à CLI já testada via `pkexec`.

**Architecture:** A GUI (`apps/gui`, React + crate `usbkeeper-gui`) roda como usuário e lê discos/histórico direto pelos crates `core`/`linux`/`history`. Operações privilegiadas executam `pkexec usbkeeper <cmd> --json --progress-json --cancel-stdin`; a GUI lê o progresso como linhas JSON no stderr e cancela escrevendo `cancel` no stdin. Tipos Rust → TS com `ts-rs` atrás da feature `ts`.

**Tech Stack:** Rust 1.99 (edition 2024), Tauri 2 (+ plugin dialog), React 19, TypeScript 7, Vite 8, Tailwind 4, zustand 5, vitest 5 + Testing Library, ts-rs 10, polkit/pkexec.

Spec: `docs/superpowers/specs/2026-11-18-m5-gui-design.md`.

## Global Constraints

- A GUI **nunca** roda como root; operações privilegiadas = `pkexec <cli> …`. A CLI continua sendo a única que grava em disco.
- A GUI passa `--yes-i-know <token>`, mas a CLI reconfere tudo (SafetyGuard, identidade, O_EXCL). Nenhuma regra de segurança é reimplementada na GUI como substituta, só como UX.
- Polkit: action `dev.usbkeeper.cli`, `exec.path=/usr/bin/usbkeeper`, defaults `auth_admin_keep`.
- Lista atualizada a cada 2 s **só com a janela visível**.
- Janela 1100×720 (mín. 760×520), tema claro/escuro do sistema, textos em pt-BR.
- Orçamento: < 250 MB de PSS com a janela aberta, < 1% de CPU parado; `WEBKIT_DISABLE_COMPOSITING_MODE=1` por padrão (`USBKEEPER_COMPOSITING=1` reativa).
- `.deb`: `/usr/bin/usbkeeper`, `/usr/bin/usbkeeper-gui`, policy em `/usr/share/polkit-1/actions/dev.usbkeeper.policy`, `.desktop`. Depends `pkexec, util-linux, udisks2`; Recommends `smartmontools, dosfstools, exfatprogs, ntfs-3g, e2fsprogs`.
- Commits sem coautoria do Claude. Compilar com no máximo 4 jobs (`.cargo/config.toml`).
- Variáveis de desenvolvimento: `USBKEEPER_CLI` (caminho da CLI), `USBKEEPER_SHOW_VIRTUAL=1` (lista loops e passa `--allow-non-usb`).

```rust
/// Caminho padrão do banco. `home` substitui o diretório do usuário (a CLI
/// passa a home de quem chamou o sudo/pkexec); `None` usa o ambiente.
pub fn default_db_path(home: Option<&Path>) -> Option<std::path::PathBuf> {
    use std::path::PathBuf;
    let dir = if let Some(home) = home {
        home.join(".local/share/usbkeeper")
    } else if cfg!(windows) {
        PathBuf::from(std::env::var_os("LOCALAPPDATA")?).join("usbkeeper")
    } else if cfg!(target_os = "macos") {
        PathBuf::from(std::env::var_os("HOME")?).join("Library/Application Support/usbkeeper")
    } else {
        std::env::var_os("XDG_DATA_HOME")
            .map(PathBuf::from)
            .or_else(|| std::env::var_os("HOME").map(|h| PathBuf::from(h).join(".local/share")))?
            .join("usbkeeper")
    };
    Some(dir.join("history.db"))
}
```

```rust
//! Modo "dirigido por programa" (usado pela interface gráfica via pkexec):
//! progresso como linhas JSON no stderr e cancelamento pela linha `cancel`
//! no stdin (o usuário não pode mandar sinal a um processo root).

use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::{Arc, OnceLock};

use std::time::{Duration, Instant};

#[derive(Debug, Clone, Copy, Default)]
pub struct Mode {
    pub progress_json: bool,
    pub cancel_stdin: bool,
}

static MODE: OnceLock<Mode> = OnceLock::new();

pub fn set(mode: Mode) {
    let _ = MODE.set(mode);
}

pub fn get() -> Mode {
    MODE.get().copied().unwrap_or_default()
}

#[derive(Serialize)]
struct Line<'a> {
    phase: &'a str,
    label: &'a str,
    done: u64,
    total: u64,
    bytes: bool,
}

pub fn progress_line(phase: Phase, done: u64, total: u64) -> String {
    serde_json::to_string(&Line {
        phase: phase.id(),
        label: phase.label(),
        done,
        total,
        bytes: phase.counts_bytes(),
    })
    .expect("serializável")
}

/// Etapa do `format` (não é uma `Phase` do core).
pub fn step_line(label: &str, done: u64, total: u64) -> String {
    serde_json::to_string(&Line {
        phase: "format",
        label,
        done,
        total,
        bytes: false,
    })
    .expect("serializável")
}

pub fn error_line(message: &str) -> String {
    serde_json::json!({ "error": message }).to_string()
}

const THROTTLE: Duration = Duration::from_millis(100);

pub struct JsonProgress<W: Write> {
    out: W,
    last: Option<(Phase, Instant)>,
}

impl<W: Write> JsonProgress<W> {
    pub fn new(out: W) -> Self {
        Self { out, last: None }
    }

    pub fn into_inner(self) -> W {
        self.out
    }
}

impl<W: Write> Progress for JsonProgress<W> {
    fn report(&mut self, phase: Phase, done: u64, total: u64) {
        let now = Instant::now();
        let emit = match self.last {
            Some((p, at)) => p != phase || done >= total || now - at >= THROTTLE,
            None => true,
        };
        if emit {
            self.last = Some((phase, now));
            let _ = writeln!(self.out, "{}", progress_line(phase, done, total));
            let _ = self.out.flush();
        }
    }
}

/// Escolhe a forma de progresso conforme as flags.
pub enum Reporter {
    Bar(Bar),
    Json(JsonProgress<std::io::Stderr>),
    Silent,
}

impl Reporter {
    pub fn new(json_output: bool) -> Self {
        if get().progress_json {
            Reporter::Json(JsonProgress::new(std::io::stderr()))
        } else if json_output {
            Reporter::Silent
        } else {
            Reporter::Bar(Bar::new())
        }
    }

    pub fn finish(&mut self) {
        if let Reporter::Bar(bar) = self {
            bar.finish();
        }
    }
}

impl Progress for Reporter {
    fn report(&mut self, phase: Phase, done: u64, total: u64) {
        match self {
            Reporter::Bar(b) => b.report(phase, done, total),
            Reporter::Json(j) => j.report(phase, done, total),
            Reporter::Silent => {}
        }
    }
}

/// Lê linhas de `reader`; `cancel` liga a flag. Fim da entrada é ignorado.
pub fn watch_reader<R: BufRead + Send + 'static>(reader: R, flag: Arc<AtomicBool>) -> JoinHandle<()> {
    std::thread::spawn(move || {
        for line in reader.lines() {
            match line {
                Ok(l) if l.trim() == "cancel" => {
                    flag.store(true, Ordering::SeqCst);
                    return;
                }
                Ok(_) => {}
                Err(_) => return,
            }
        }
    })
}

pub fn watch_stdin(flag: Arc<AtomicBool>) {
    let _ = watch_reader(std::io::BufReader::new(std::io::stdin()), flag);
}
```

```rust
pub struct Invoker {
    pub home: PathBuf,
    pub uid: u32,
    pub gid: u32,
}

pub enum Lookup<'a> {
    Name(&'a str),
    Uid(u32),
}

pub fn passwd_entry(passwd: &str, by: Lookup<'_>) -> Option<Invoker> {
    passwd.lines().find_map(|line| {
        let f: Vec<&str> = line.split(':').collect();
        if f.len() < 6 {
            return None;
        }
        let uid: u32 = f[2].parse().ok()?;
        let hit = match by {
            Lookup::Name(n) => f[0] == n,
            Lookup::Uid(u) => uid == u,
        };
        hit.then(|| Invoker {
            home: PathBuf::from(f[5]),
            uid,
            gid: f[3].parse().unwrap_or(uid),
        })
    })
}

/// Quem chamou de verdade quando rodando como root via sudo ou pkexec.
fn invoker() -> Option<Invoker> {
    if !cfg!(unix) {
        return None;
    }
    let passwd = std::fs::read_to_string("/etc/passwd").ok()?;
    if let Ok(user) = std::env::var("SUDO_USER")
        && user != "root"
    {
        return passwd_entry(&passwd, Lookup::Name(&user));
    }
    let uid: u32 = std::env::var("PKEXEC_UID").ok()?.parse().ok()?;
    (uid != 0).then(|| passwd_entry(&passwd, Lookup::Uid(uid))).flatten()
}

pub fn db_path() -> Option<PathBuf> {
    std::env::var_os("USBKEEPER_DB")
        .map(PathBuf::from)
        .or_else(|| usbkeeper_history::default_db_path(invoker().as_ref().map(|i| i.home.as_path())))
}

pub fn give_back(path: &Path) {
    #[cfg(unix)]
    if let Some(i) = invoker() {
        let _ = std::os::unix::fs::chown(path, Some(i.uid), Some(i.gid));
    }
    #[cfg(not(unix))]
    let _ = path;
}
```

```rust
//! Leitura sem privilégio: discos, quem os usa e histórico.

use serde::Serialize;
use ts_rs::TS;
use usbkeeper_core::safety::{self, Policy, Refusal};
use usbkeeper_core::{Device, Holder};
use usbkeeper_history::{DeviceInfo, DeviceSummary, Event, History, kind};

#[derive(Debug, Clone, Serialize, TS)]
#[ts(export)]
pub struct DeviceView {
    pub device: Device,
    pub refusals: Vec<Refusal>,
    pub is_system: bool,
    pub confirmation_token: String,
    pub history_key: String,
    pub last_fake_verdict: Option<String>,
    pub last_health_verdict: Option<String>,
    #[ts(type = "number | null")]
    pub suggested_max_bytes: Option<u64>,
}

pub fn show_virtual() -> bool {
    std::env::var_os("USBKEEPER_SHOW_VIRTUAL").is_some()
}

fn info(d: &Device) -> DeviceInfo {
    DeviceInfo {
        serial: d.serial.clone(),
        vendor_id: d.usb.as_ref().map(|u| u.vendor_id.clone()),
        product_id: d.usb.as_ref().map(|u| u.product_id.clone()),
        model: Some(d.display_name()),
        advertised_bytes: d.size_bytes,
    }
}

pub fn device_view(device: Device, summaries: &[DeviceSummary], last_fake: Option<&Event>) -> DeviceView {
    let policy = Policy { allow_non_usb: show_virtual() };
    let key = info(&device).key();
    let summary = summaries.iter().find(|s| s.device.key == key);
    DeviceView {
        refusals: safety::check_target(&device, policy),
        is_system: safety::system_mountpoint(&device).is_some(),
        confirmation_token: safety::confirmation_token(&device).to_string(),
        last_fake_verdict: summary.and_then(|s| s.last_fake_verdict.clone()),
        last_health_verdict: summary.and_then(|s| s.last_health_verdict.clone()),
        suggested_max_bytes: last_fake
            .filter(|e| e.verdict.as_deref() == Some("fake"))
            .and_then(|e| e.data.get("suggested_max_bytes")?.as_u64()),
        history_key: key,
        device,
    }
}

fn open_history() -> Option<History> {
    let path = std::env::var_os("USBKEEPER_DB")
        .map(std::path::PathBuf::from)
        .or_else(|| usbkeeper_history::default_db_path(None))?;
    path.exists().then(|| History::open(&path).ok()).flatten()
}

#[cfg(target_os = "linux")]
fn enumerate() -> Result<Vec<Device>, String> {
    use usbkeeper_core::Enumerator;
    usbkeeper_linux::LinuxEnumerator { include_virtual: show_virtual(), ..Default::default() }
        .list()
        .map_err(|e| e.to_string())
}

#[cfg(not(target_os = "linux"))]
fn enumerate() -> Result<Vec<Device>, String> {
    Err("plataforma ainda não suportada pela interface".into())
}

#[tauri::command]
pub fn list_devices() -> Result<Vec<DeviceView>, String> {
    let devices = enumerate()?;
    let history = open_history();
    let summaries = history.as_ref().and_then(|h| h.devices().ok()).unwrap_or_default();
    let mut views: Vec<DeviceView> = devices
        .into_iter()
        .map(|d| {
            let key = info(&d).key();
            let events = history.as_ref().and_then(|h| h.events(&key).ok()).unwrap_or_default();
            let last_fake = events.iter().rev().find(|e| e.kind == kind::FAKE_CHECK);
            device_view(d, &summaries, last_fake)
        })
        .collect();
    // USB primeiro, sistema por último.
    views.sort_by_key(|v| (v.is_system, v.device.transport != usbkeeper_core::Transport::Usb, v.device.name.clone()));
    Ok(views)
}

/// WSL2 não enxerga USB do Windows: a lista vazia mostra a dica do usbipd.
#[tauri::command]
pub fn usb_hint() -> Option<String> {
    #[cfg(target_os = "linux")]
    if usbkeeper_linux::wsl::running_in_wsl() {
        return Some(usbkeeper_linux::wsl::USBIPD_HINT.to_string());
    }
    None
}

#[tauri::command]
pub fn device_holders(path: String) -> Vec<Holder> {
    #[cfg(target_os = "linux")]
    {
        use usbkeeper_core::{Enumerator, Mounts};
        let e = usbkeeper_linux::LinuxEnumerator { include_virtual: true, ..Default::default() };
        if let Ok(d) = e.get(&path) {
            return usbkeeper_linux::LinuxMounts.holders(&d);
        }
    }
    let _ = path;
    Vec::new()
}

#[tauri::command]
pub fn history_events(key: String) -> Result<Vec<Event>, String> {
    match open_history() {
        None => Ok(Vec::new()),
        Some(h) => h.events(&key).map_err(|e| e.to_string()),
    }
}
```

```ts
export function humanBytes(bytes: number): string {
  const units = ["B", "KB", "MB", "GB", "TB", "PB"];
  let value = bytes;
  let unit = 0;
  while (value >= 1000 && unit < units.length - 1) { value /= 1000; unit++; }
  return unit === 0 ? `${bytes} B` : `${value.toFixed(1)} ${units[unit]}`;
}

export function duration(secs: number): string {
  const s = Math.max(0, Math.floor(secs));
  if (s >= 3600) return `${Math.floor(s / 3600)}h${String(Math.floor((s % 3600) / 60)).padStart(2, "0")}min`;
  if (s >= 60) return `${Math.floor(s / 60)}min${String(s % 60).padStart(2, "0")}s`;
  return `${s}s`;
}

const LABELS: Record<string, string> = {
  genuine: "genuíno", fake: "FALSO", damaged: "defeito", good: "saudável", warning: "atenção",
  failing: "FALHANDO", unknown: "sem SMART", clean: "sem erros", unreadable: "ILEGÍVEL",
};
export const verdictLabel = (v?: string | null) => (v ? LABELS[v] ?? v : "");

export function verdictTone(v?: string | null): "ok" | "warn" | "bad" | "muted" {
  if (v === "genuine" || v === "good" || v === "clean") return "ok";
  if (v === "warning" || v === "damaged") return "warn";
  if (v === "fake" || v === "failing" || v === "unreadable") return "bad";
  return "muted";
}
```

```rust
//! Tradução de pedidos da interface em argumentos da CLI e leitura do stream
//! `--progress-json` (puro, sem processos).

use serde::{Deserialize, Serialize};
use ts_rs::TS;

#[derive(Debug, Clone, Serialize, Deserialize, TS)]
#[serde(tag = "kind", rename_all = "snake_case")]
#[ts(export)]
pub enum OpRequest {
    FakeCheck { device: String, full: bool },
    Health { device: String, scan: bool },
    Bench { device: String, write: bool },
    Format {
        device: String,
        filesystem: String,
        table: Option<String>,
        label: Option<String>,
        #[ts(type = "number | null")]
        max_bytes: Option<u64>,
    },
    Eject { device: String },
}

impl OpRequest {
    pub fn device(&self) -> &str {
        match self {
            OpRequest::FakeCheck { device, .. } | OpRequest::Health { device, .. } | OpRequest::Bench { device, .. }
            | OpRequest::Format { device, .. } | OpRequest::Eject { device } => device,
        }
    }

    pub fn kind(&self) -> &'static str {
        match self {
            OpRequest::FakeCheck { .. } => "fake_check",
            OpRequest::Health { .. } => "health",
            OpRequest::Bench { .. } => "bench",
            OpRequest::Format { .. } => "format",
            OpRequest::Eject { .. } => "eject",
        }
    }

    /// Eject usa udisks e não precisa de root.
    pub fn needs_root(&self) -> bool {
        !matches!(self, OpRequest::Eject { .. })
    }
}

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize, TS)]
#[ts(export)]
pub struct OpProgress {
    pub phase: String,
    pub label: String,
    #[ts(type = "number")]
    pub done: u64,
    #[ts(type = "number")]
    pub total: u64,
    pub bytes: bool,
}

pub fn args(req: &OpRequest, token: &str, allow_non_usb: bool) -> Vec<String> {
    let mut a: Vec<String> = Vec::new();
    let mut push = |x: &str| a.push(x.to_string());
    let confirm = |a: &mut Vec<String>| {
        a.extend(["--unmount".into(), "--yes-i-know".into(), token.to_string()]);
    };
    match req {
        OpRequest::FakeCheck { device, full } => {
            push("fake-check"); push(device);
            if *full { push("--full"); }
            confirm(&mut a);
        }
        OpRequest::Health { device, scan } => {
            push("health"); push(device);
            if *scan { push("--scan"); }
        }
        OpRequest::Bench { device, write } => {
            push("bench"); push(device);
            if *write { push("--write"); confirm(&mut a); }
        }
        OpRequest::Format { device, filesystem, table, label, max_bytes } => {
            push("format"); push(device); push("--fs"); push(filesystem);
            if let Some(t) = table { a.extend(["--table".into(), t.clone()]); }
            if let Some(l) = label.as_deref().filter(|l| !l.trim().is_empty()) { a.extend(["-l".into(), l.to_string()]); }
            if let Some(m) = max_bytes { a.extend(["--max-size".into(), m.to_string()]); }
            confirm(&mut a);
        }
        OpRequest::Eject { device } => {
            a.extend(["eject".into(), device.clone(), "--json".into()]);
            return a;
        }
    }
    if allow_non_usb { a.push("--allow-non-usb".into()); }
    a.extend(["--json".into(), "--progress-json".into(), "--cancel-stdin".into()]);
    a
}

#[derive(Debug, Clone, PartialEq)]
pub enum StreamLine {
    Progress(OpProgress),
    Error(String),
    Log(String),
}

pub fn parse_line(line: &str) -> StreamLine {
    let t = line.trim();
    if t.starts_with('{') {
        if let Ok(p) = serde_json::from_str::<OpProgress>(t) {
            return StreamLine::Progress(p);
        }
        if let Ok(v) = serde_json::from_str::<serde_json::Value>(t)
            && let Some(e) = v.get("error").and_then(|e| e.as_str())
        {
            return StreamLine::Error(e.to_string());
        }
    }
    StreamLine::Log(t.to_string())
}

/// Mensagem de erro final; `None` = sucesso.
pub fn exit_message(code: Option<i32>, cli_error: Option<&str>) -> Option<String> {
    match code {
        Some(0) => None,
        Some(126) => Some("autorização cancelada".into()),
        Some(127) => Some("autorização negada (ou pkexec ausente)".into()),
        _ => Some(cli_error.map(String::from).unwrap_or_else(|| "a operação falhou".into())),
    }
}
```

```rust
//! Execução das operações: `pkexec <cli> …` com stdin/stderr ligados, eventos
//! de progresso e cancelamento pela linha `cancel`.

use std::collections::HashMap;
use std::io::{BufRead, BufReader, Read, Write};
use std::path::PathBuf;
use std::process::{ChildStdin, Command, Stdio};
use std::sync::atomic::{AtomicU64, Ordering};
use std::sync::Mutex;

use serde::Serialize;
use tauri::{AppHandle, Emitter, State};
use ts_rs::TS;

use crate::cli::{self, OpProgress, OpRequest, StreamLine};
use crate::devices::show_virtual;

#[derive(Default)]
pub struct Ops {
    next: AtomicU64,
    running: Mutex<HashMap<String, (u64, ChildStdin)>>,
}

#[derive(Clone, Serialize, TS)]
#[ts(export)]
pub struct OpEvent {
    #[ts(type = "number")]
    pub id: u64,
    pub device: String,
    pub progress: OpProgress,
}

#[derive(Clone, Serialize, TS)]
#[ts(export)]
pub struct OpFinished {
    #[ts(type = "number")]
    pub id: u64,
    pub device: String,
    pub kind: String,
    pub ok: bool,
    #[ts(type = "any")]
    pub result: Option<serde_json::Value>,
    pub error: Option<String>,
}

/// CLI usada: USBKEEPER_CLI, depois `usbkeeper` ao lado do executável da GUI
/// (target/debug em desenvolvimento), depois /usr/bin/usbkeeper.
pub fn cli_path() -> PathBuf {
    if let Some(p) = std::env::var_os("USBKEEPER_CLI") {
        return PathBuf::from(p);
    }
    if let Ok(exe) = std::env::current_exe()
        && let Some(dir) = exe.parent()
    {
        let sibling = dir.join("usbkeeper");
        if sibling.is_file() {
            return sibling;
        }
    }
    PathBuf::from("/usr/bin/usbkeeper")
}

#[tauri::command]
pub fn start_operation(app: AppHandle, ops: State<'_, Ops>, request: OpRequest, token: String) -> Result<u64, String> {
    let device = request.device().to_string();
    let mut running = ops.running.lock().map_err(|e| e.to_string())?;
    if running.contains_key(&device) {
        return Err("já existe uma operação em andamento neste disco".into());
    }
    let cli = cli_path();
    let args = cli::args(&request, &token, show_virtual());
    let mut cmd = if request.needs_root() {
        let mut c = Command::new("pkexec");
        c.arg(&cli);
        c
    } else {
        Command::new(&cli)
    };
    let mut child = cmd
        .args(&args)
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::piped())
        .spawn()
        .map_err(|e| format!("não foi possível iniciar {}: {e}", cli.display()))?;
    let id = ops.next.fetch_add(1, Ordering::Relaxed) + 1;
    let stdin = child.stdin.take().expect("stdin piped");
    let stderr = child.stderr.take().expect("stderr piped");
    let mut stdout = child.stdout.take().expect("stdout piped");
    running.insert(device.clone(), (id, stdin));
    drop(running);

    let kind = request.kind().to_string();
    std::thread::spawn(move || {
        let mut last_error: Option<String> = None;
        for line in BufReader::new(stderr).lines().map_while(Result::ok) {
            match cli::parse_line(&line) {
                StreamLine::Progress(progress) => {
                    let _ = app.emit("op-progress", OpEvent { id, device: device.clone(), progress });
                }
                StreamLine::Error(e) => last_error = Some(e),
                StreamLine::Log(_) => {}
            }
        }
        let mut out = String::new();
        let _ = stdout.read_to_string(&mut out);
        let status = child.wait().ok().and_then(|s| s.code());
        if let Some(state) = app.try_state::<Ops>() {
            if let Ok(mut r) = state.running.lock() {
                r.remove(&device);
            }
        }
        let error = cli::exit_message(status, last_error.as_deref());
        let _ = app.emit("op-finished", OpFinished {
            id,
            device,
            kind,
            ok: error.is_none(),
            result: serde_json::from_str(out.trim()).ok(),
            error,
        });
    });
    Ok(id)
}

#[tauri::command]
pub fn cancel_operation(ops: State<'_, Ops>, device: String) -> Result<(), String> {
    let mut running = ops.running.lock().map_err(|e| e.to_string())?;
    match running.get_mut(&device) {
        Some((_, stdin)) => stdin.write_all(b"cancel\n").and_then(|_| stdin.flush()).map_err(|e| e.to_string()),
        None => Err("nenhuma operação em andamento neste disco".into()),
    }
}
```

```tsx
import type { RunningOp } from "../../lib/store";
import { duration, humanBytes } from "../../lib/format";

export function eta(op: RunningOp, now: number): string | null {
  const p = op.progress;
  if (!p || !p.bytes || p.done === 0) return null;
  const secs = (now - op.phaseStartedAt) / 1000;
  if (secs < 0.5) return null;
  const rate = p.done / secs;
  return `${humanBytes(rate)}/s · restam ~${duration((p.total - p.done) / rate)}`;
}

export function OperationBar({ op, onCancel, now = Date.now() }: { op: RunningOp; onCancel: () => void; now?: number }) {
  const p = op.progress;
  const pct = p && p.total > 0 ? Math.min(100, (p.done * 100) / p.total) : 0;
  const extra = eta(op, now);
  return (
    <div role="status" className="flex items-center gap-3 border-b px-6 py-2 text-sm" style={{ borderColor: "var(--line)", background: "var(--bg)" }}>
      <span className="w-56 truncate">{p ? p.label : "aguardando autorização…"}</span>
```

```ts
export type Fs = "fat32" | "exfat" | "ntfs" | "ext4";
export const FS: { id: Fs; hint: string; max: number }[] = [
  { id: "exfat", hint: "Windows/macOS/Linux, sem limite de 4 GB; melhor para pendrive", max: 15 },
  { id: "fat32", hint: "compatível com tudo (TV, som, carro, BIOS); arquivos até 4 GB", max: 11 },
  { id: "ntfs", hint: "Windows; leitura/escrita no Linux, só leitura no macOS", max: 32 },
  { id: "ext4", hint: "somente Linux; permissões e journaling", max: 16 },
];
const FORBIDDEN = "\"*+,./:;<=>?[\\]|";
const bytes = (s: string) => new TextEncoder().encode(s).length;

export function validateLabel(fs: Fs, raw: string): { value: string | null; error: string | null } {
  let label = raw.trim();
  if (!label) return { value: null, error: null };
  if (fs === "fat32") {
    const bad = [...label].find((c) => FORBIDDEN.includes(c));
    if (bad) return { value: null, error: `o rótulo FAT32 não pode conter '${bad}'` };
    if (![...label].every((c) => c.charCodeAt(0) < 128)) return { value: null, error: "o rótulo FAT32 deve usar só caracteres ASCII (sem acentos)" };
    label = label.toUpperCase();
  }
  const max = FS.find((f) => f.id === fs)!.max;
  if (bytes(label) > max) return { value: null, error: `rótulo grande demais para ${fs}: ${bytes(label)} bytes (máximo ${max})` };
  return { value: label, error: null };
}
```

```ts
import { useState } from "react";
import { startOperation } from "../../lib/api";
import { useApp } from "../../lib/store";
import type { DeviceView } from "../../lib/bindings/DeviceView";
import type { OpRequest } from "../../lib/bindings/OpRequest";

/** Inicia operações do disco; destrutivas passam antes pela confirmação. */
export function useOperation(view: DeviceView) {
  const path = view.device.path;
  const running = useApp((s) => s.ops[path]);
  const finished = useApp((s) => s.finished[path] ?? {});
  const opStarted = useApp((s) => s.opStarted);
  const [pending, setPending] = useState<{ req: OpRequest; title: string; lines: string[] } | null>(null);
  const [error, setError] = useState<string | null>(null);

  const launch = (req: OpRequest) => {
    setError(null);
    startOperation(req, view.confirmation_token)
      .then((id) => opStarted(path, id, req.kind))
      .catch((e) => setError(String(e)));
  };

  const run = (req: OpRequest, confirm?: { title: string; lines: string[] }) => {
    if (confirm) setPending({ req, ...confirm });
    else launch(req);
  };

  return {
    run, running, error,
    last: (kind: string) => finished[kind],
    confirm: pending && {
      ...pending,
      onConfirm: () => { launch(pending.req); setPending(null); },
      onClose: () => setPending(null),
    },
  };
}
```

```bash
#!/usr/bin/env bash
# Mede PSS (MB) e CPU (%) do usbkeeper-gui e dos filhos WebKit por N segundos.
set -euo pipefail
secs=${1:-60}
pid=$(pgrep -x usbkeeper-gui | head -1) || { echo "abra o usbkeeper-gui primeiro"; exit 1; }
pids() { echo "$pid"; pgrep -P "$pid" || true; }
pss() { local t=0; for p in $(pids); do t=$(( t + $(awk '/^Pss:/{print $2}' /proc/$p/smaps_rollup 2>/dev/null || echo 0) )); done; echo $(( t / 1024 )); }
ticks() { local t=0; for p in $(pids); do t=$(( t + $(awk '{print $14+$15}' /proc/$p/stat 2>/dev/null || echo 0) )); done; echo "$t"; }
hz=$(getconf CLK_TCK); t0=$(ticks); sleep "$secs"; t1=$(ticks)
echo "PSS: $(pss) MB   CPU: $(awk -v d=$(( t1 - t0 )) -v hz="$hz" -v s="$secs" 'BEGIN{printf "%.2f", d*100/hz/s}')%"
```
